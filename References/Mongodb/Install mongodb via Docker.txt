Install mongodb via Docker
==========================
Pull and run latest mongo image from docker hub.

    docker run -d \
      --name <container_name> \
      -p <host_port>:27017 \
      -e MONGO_INITDB_ROOT_USERNAME=<username> \
      -e MONGO_INITDB_ROOT_PASSWORD=<password> \
      mongo:latest

    Example: I choose mongodb as the container name, 27017 as the host port, admin as the username, and secret as the password.

    $ docker run -d --name mongodb -p 27017:27017 -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=secret mongo:latest

View container logs
===================
To see the container logs.

    $ docker logs mongodb

Start Interactive Docker Terminal (Bash Shell) to Manage MongoDB Database
=========================================================================

1. The container is currently running in detached mode. Connect to the container using the interactive terminal instead:
    $ docker exec -it mongodb bash
    root@8a6028a61f62:/#

2. Connect via mongosh ( using username/password is you have set up) in Docker container. (Note: mongosh is new mongo equivalent).

    $ docker exec -it mongodb bash
    root@00d21a75b44e:/# mongosh -u admin -p secret --authenticationDatabase admin
    OR,
    root@00d21a75b44e:/# mongosh -u admin -p secret 


Stopping and Restarting MongoDB Database
========================================

User docker start/stop to start mongo server container.

    Here our container name is: mongodb. Hence execute following:-

    $ docker stop mongodb
    $ docker ps
    $ docker start mongodb
    $ docker ps

    Example:
    $ docker stop mongodb
    mongodb

    $ docker ps -a
    CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS                     PORTS     NAMES
    00d21a75b44e   mongo:latest   "docker-entrypoint.s…"   4 minutes ago   Exited (0) 5 seconds ago             mongodb

Mongosh
=======

Install mongosh cli in ubuntu to connect mongodb externally (ouside docker container). To connect use: 

    $ mongosh --host localhost --port 27017 -u admin -p secret


Mongo compass GUI client
========================

Install mongo compass and use following connection parameters to connect from PC to mongodb container.

If connecting directly:
    mongodb://localhost:27017

OR, 
If connecting via user credentials of user "admin".
    mongodb://admin:secret@localhost:27017/?authMechanism=DEFAULT&authSource=admin

Mongo extention in VSCode
=========================
In VSCode install extension "mongodb for vscode" and connect to mongodb container. To connect use:

    mongodb://admin:secret@localhost:27017/
