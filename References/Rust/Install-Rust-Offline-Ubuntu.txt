Prerequisite: Rust needs C/C++ libs. Hence, install build-essential package in ubuntu.

		$ sudo apt update && sudo apt install build-essential

Step 1. Download offline version at https://forge.rust-lang.org/infra/other-installation-methods.html

		Choose the platform as: x86_64-unknown-linux-gnu
		
		I downloaded: rust-1.93.0-x86_64-unknown-linux-gnu.tar.xz

Step 2. Extract the archive file rust-1.93.0-x86_64-unknown-linux-gnu.tar.xz and do offline local install (without sudo)

		$ tar -xzf rust-1.93.0-x86_64-unknown-linux-gnu.tar.xz
		$ cd rust-1.93.0-x86_64-unknown-linux-gnu
		$ ./install.sh --prefix=$HOME/.local
		
	    This will install in your $HOME/.local/bin
	    
	    Please ensure $HOME/.local/bin is added to your PATH.
	    
Step 3. Verify installation.

		$ rustc --version
		rustc 1.93.0 (254b59607 2026-01-19)
		$ cargo --version
		cargo 1.93.0 (083ac5135 2025-12-15)
