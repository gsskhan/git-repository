How to install oracle db free image in ubuntu.
==============================================

Step 1. Pull the image you desire. I choose 23-slim-faststart.

	-slim -> An image focussed on smallest possible image size instead of additional functionality.
	*-faststart -> The same image flavor as above but with an already expanded and ready-to-go database inside the image. 
	               This image trades image size on disk for a faster database startup time.

	docker pull gvenzl/oracle-free:23-slim-faststart

Step 2. Run a new database container (data is removed when the container is removed, but kept throughout container restarts):

	docker run -d -p 1521:1521 --name oracledb \
	-e ORACLE_PASSWORD=<your password> \
	-e APP_USER=<new schema/user> \
	-e APP_USER_PASSWORD=<new schema/user password> \
	gvenzl/oracle-free:<tag>
	
	Note: 
	It will create a new database schema user (specified by variable APP_USER) with the name specified in this variable 
	and password (specified by variable APP_USER_PASSWORD).	For 18c and onwards, the user will be created in the default FREEPDB1 pluggable database.
	
	Example:
	
		$ docker run -d --name oracledb -p 1521:1521 -e ORACLE_PASSWORD=strongpassword -e APP_USER=NARCO -e APP_USER_PASSWORD=password gvenzl/oracle-free:23-slim-faststart

Step 3. View the logs of container. And note the DB name. By default FREEPDB1 gets created.

	Example:
	
		$ docker logs oracledb
		
Step 4: To start and stop the oracledb

	Example:
		$ docker stop oracledb
		$ docker start oracledb
		
Step 5. Connect via sql developer to SYS, SYSTEM & narco (The schema/user created by variable APP_USER). Refer screenshots.

		Note: We can use the narco schema for application development activities.
		
		Hostname: localhost or 127.0.0.1
		Port: 1521
		Service name: FREEPDB1
		Database App User: NARCO
		Database App Password: password
