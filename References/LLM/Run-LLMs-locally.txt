======================================================================================
Run LLM locally in your PC/Laptop
======================================================================================

Ollama is an open-source platform that simplifies running large language models (LLMs) 
like Llama 2 and Gemma on your local machine. It provides an easy-to-use interface for
downloading, managing, and interacting with these models, allowing users to experiment
with and build AI applications without needing to rely on external APIs or cloud services.

===================

===================
Manual Approach
===================

1. Download from https://ollama.com/download/ollama-linux-amd64.tgz and extract to your home.

2. Setup PATH

	$ export PATH=$HOME/ollama-linux-amd64/bin/:$PATH

3. Now start ollama

    $ ollama serve

	It will start a REST endpoints too.

	GET http://localhost:11434/api/ps
	GET http://localhost:11434/api/version

	Above if returns results, then its good to go.

4. Run one of the models available at https://ollama.com

	$ ollama ps
	NAME    ID    SIZE    PROCESSOR    UNTIL
