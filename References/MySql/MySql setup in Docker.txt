If containerization was successful, you should see the container when you run 'docker ps -a' from your terminal.

	$ docker images
	REPOSITORY   TAG       IMAGE ID       CREATED        SIZE
	mysql        8         78e963ded248   2 months ago   769MB

	$ docker ps -a
	CONTAINER ID   IMAGE     COMMAND                  CREATED              STATUS              PORTS                                                                                      NAMES
	d2a89e28de9a   mysql:8   "docker-entrypoint.s…"   About a minute ago   Up About a minute   0.0.0.0:3306->3306/tcp, :::3306->3306/tcp, 0.0.0.0:33060->33060/tcp, :::33060->33060/tcp   mysqldb

At this point you will have a running container with MySQL running inside of it. 
You can connect to the database using your terminal or from your local application by providing password value of variable MYSQL_ROOT_PASSWORD.

You should now also be able to connect directly to the containerized database from your terminal via remote connection.

	Remote connection: mysql -h 127.0.0.1 -P 3306  -u root -p
