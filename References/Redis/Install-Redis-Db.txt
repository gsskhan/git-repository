================================
To install Redis db using Docker
================================

Step 1. Download and run redis db.

    Syntax:  docker run -d --name <name of container> -p 6379:6379 redis
    Example:

    redisdb: This assigns a name to your Redis container, making it easier to identify and manage.
    -d: This flag runs the container in detached mode.
    -p 6379:6379: This maps port 6379 on your host machine to port 6379 inside the container, allowing external applications to connect to Redis.
    redis: This specifies the Redis image to use.

Step 2. Connect to Redis from inside the container.

    Syntax: docker exec -it <name of container> sh
    Example:
            $ docker exec -it redisdb sh
              # redis-cli
              127.0.0.1:6379> ping
              PONG
              127.0.0.1:6379>

    OR,

    Syntax: docker exec -it <name of container> redis-cli 
    Example:
            $ docker exec -it redisdb redis-cli
              127.0.0.1:6379> ping
              PONG
              127.0.0.1:6379> 

Step 3. Connect to Redis from outside the container.
    
    [Not my preferred method] 
    Install redis-cli in ubuntu.
    Syntax: sudo apt install redis-tools
    Example:
            $ sudo apt install redis-tools

    Next, use redis-cli to connect.
    Syntax: redis-cli -h redis_server_endpoint -p port_number
    Example:    
            $ redis-cli -h localhost -p 6379
            127.0.0.1:6379> ping
            PONG        
    
    OR,

    [My preffered method]
    Install "Redis" extension in vscode and connect.
    Use=> host: localhost , Port: 6379

Step 4. Start/Stop redis

    Syntax: docker start <name of container>
            docker stop <name of container>
    Example:
            $ docker start redisdb
            $ docker stop redisdb
