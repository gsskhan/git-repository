Step 2: The postgres db instance will be accesible with following properties:

		Host: localhost
		Port: 5432
		Username: postgres
		Password: (whatever I set it to above as value of POSTGRES_PASSWORD) 
		Database: postgres
		
Step 3: (Optional)  Docker commands

	To see db logs:            $ docker  logs postgres
	To stop the db container:  $ docker  stop postgres
	To start the db container: $ docker start postgres
	
	
===================================================
To connect via commandline from ubuntu install psql
===================================================

Step 1. Update the package list:       sudo apt update
Step 2. Install the PostgreSQL client: sudo apt install postgresql-client
Step 3. Verify the installation:       psql --version
Step 4. Start using psql: (Syntax)     psql -h <hostname or ip address> -p <port> -d <database name which you want to connect> -U <username of the database server>

        $ psql -h localhost -p 5432 -d postgres -U postgres
